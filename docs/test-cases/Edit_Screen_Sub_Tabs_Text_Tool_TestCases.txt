  1. Sub-Tab "Fonts"       : Lựa chọn và áp dụng phông chữ nghệ thuật đa dạng
  2. Sub-Tab "Color"       : Màu đơn sắc (Solid), Chuyển sắc (Gradient), Họa tiết (Texture), Độ mờ (Opacity)

  5. Sub-Tab "Outline"     : Độ dày đường viền (Outline Width) và Màu viền chữ (Outline Color)
  6. Sub-Tab "Curve"       : Uốn cong chữ (Curve), Khoảng cách dòng (Line Spacing), Giãn cách ký tự (Char Spacing)
  7. Sub-Tab "3D"          : Xoay không gian 3 chiều theo trục X (X-Rotation), trục Y (Y-Rotation), trục Z (Z-Rotation)
