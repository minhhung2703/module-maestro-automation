NHÓM 1: SỬ DỤNG TÍNH NĂNG BACKGROUND VÀ THỰC HIỆN LƯU LẠI
----------------------------------------------------------------------------------------------------

[TC_FEAT_BG_01] Thay đổi màu nền đơn sắc (Solid Color) của Background và thực hiện lưu lại
- Mục tiêu: Đảm bảo khi người dùng đổi màu nền thiết kế sang màu mới, thao tác lưu giữ nguyên màu nền này trên ảnh xuất ra và dự án.
- Điều kiện tiên quyết: Màn hình Edit Screen đang mở Restaurant Template #1.
- Các bước thực hiện:
  1. Nhấn vào tab "Background" (`itemBackground`) trên thanh bottom bar.
  2. Tại sub-tab "Color", chọn một màu bất kỳ (ví dụ: màu đỏ hoặc màu vàng).
  3. Quan sát nền canvas đổi màu thành công.
  4. Nhấn icon Save ở góc phải phía trên (`mnItemSave`).
  5. Chọn "Export Logo (PNG)" (`llExportLogo`) -> Chọn độ phân giải HD -> Nhấn "SAVE" (`tvSave`).
  6. Xử lý màn hình quảng cáo / popup đánh giá để chuyển tới Preview Screen.
- Kết quả mong đợi:
  + Nền canvas trên màn Edit đổi màu chính xác.
  + Màn hình Preview hiển thị logo với màu nền mới vừa chọn, không bị quay lại màu nền ban đầu.
  + Tệp ảnh PNG trong thư viện lưu trữ có màu nền đồng nhất với màn Preview.
- Maestro Selector:
  + tapOn: { id: "itemBackground" }
  + tapOn: { point: "20%, 85%" }
  + tapOn: { id: "mnItemSave" }
  + tapOn: { id: "llExportLogo" }
  + tapOn: { id: "tvSave" }
  + extendedWaitUntil: { visible: "Preview", timeout: 10000 }
  + assertVisible: "Preview"

[TC_FEAT_BG_02] Áp dụng Gradient nền cho thiết kế và thực hiện lưu lại
- Mục tiêu: Xác minh hiệu ứng màu chuyển sắc (Gradient) nền được kết xuất đầy đủ khi lưu và xuất ảnh.
- Các bước thực hiện:
  1. Nhấn tab "Background" -> Chọn sub-tab "Gradient".
  2. Chọn một mẫu gradient 2 màu trong danh sách.
  3. Nhấn icon Save (`mnItemSave`) -> Chọn "Export Logo (PNG)" -> Nhấn "SAVE".
  4. Vượt qua quảng cáo và kiểm tra màn hình Preview.
- Kết quả mong đợi:
  + Dải màu chuyển tiếp mượt mà trên canvas.
  + Màn hình Preview hiển thị đúng dải gradient nền vừa chọn.

[TC_FEAT_BG_03] Áp dụng Texture hoa văn nền và thực hiện lưu lại
- Mục tiêu: Đảm bảo hoa văn chất liệu (gỗ, đá, vải, grunge) trên nền logo được xuất chính xác sang file ảnh.
- Các bước thực hiện:
  1. Nhấn tab "Background" -> Chọn sub-tab "Texture".
  2. Chọn một mẫu texture hoa văn trong danh sách.
  3. Nhấn icon Save (`mnItemSave`) -> Chọn "Export Logo (PNG)" -> Nhấn "SAVE".
  4. Quan sát kết quả tại màn hình Preview.
- Kết quả mong đợi:
  + Hoa văn texture hiển thị sắc nét trên màn hình Preview.

[TC_FEAT_BG_04] Điều chỉnh độ trong suốt nền (Background Opacity) và thực hiện lưu lại
- Mục tiêu: Kiểm tra giá trị Opacity của nền khi kéo thanh trượt được phản ánh chính xác sau khi lưu.
- Các bước thực hiện:
  1. Nhấn tab "Background".
  2. Kéo thanh trượt độ mờ nền từ 100% xuống khoảng 50%.
  3. Nhấn icon Save (`mnItemSave`) -> Chọn "Export Logo (PNG)" -> Nhấn "SAVE".
  4. Quan sát kết quả tại màn hình Preview.
- Kết quả mong đợi:
  + Nền logo hiển thị mờ đục 50% trên lưới caro trong suốt ở màn hình Preview.
