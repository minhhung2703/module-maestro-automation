NHÓM 1: UI & VISUAL DISPLAY TEST CASES (Kiểm thử Giao diện & Hiển thị)
----------------------------------------------------------------------------------------------------

[TC_HOME_UI_01] Kiểm tra hiển thị tổng thể giao diện Home Screen
- Mục tiêu: Đảm bảo toàn bộ các thành phần trên Home Screen hiển thị đầy đủ, không vỡ layout.
- Điều kiện tiên quyết: Ứng dụng đã khởi động và đang ở màn hình Home.
- Các bước thực hiện:
  1. Mở màn hình Home.
  2. Kiểm tra hiển thị Toolbar gồm Hamburger Menu, tiêu đề "Logos4U", nút VIP và Hộp quà.
  3. Kiểm tra hiển thị đầy đủ 6 thẻ tính năng: Template, AI Studio, Create Logo, Auto Design, My Logo, My Design.
  4. Kiểm tra hiển thị Banner IAP ở phía dưới cùng.
- Kết quả mong đợi:
  + Tất cả các icon, text tiêu đề, mô tả hiển thị sắc nét, đúng font chữ, đúng màu sắc.
  + Không có element nào bị chồng chéo hay che khuất.
- Maestro Selectors:
  + assertVisible: "Logos4U"
  + assertVisible: { id: "btnTemplate" }
  + assertVisible: { id: "btnStyleMagicAI" }
  + assertVisible: { id: "btnCreateLogo" }
  + assertVisible: { id: "btnLogoWizard" }
  + assertVisible: { id: "btnMyDesignImageFile" }
  + assertVisible: { id: "btnMyDesignFile" }

[TC_HOME_UI_02] Visual Regression Testing - So sánh với ảnh Baseline Home Screen
- Mục tiêu: So sánh ảnh chụp runtime của màn hình Home với ảnh mẫu chuẩn trong assets/.
- Điều kiện tiên quyết: Đã có ảnh baseline assets/Home_Screen.png.
- Các bước thực hiện:
  1. Đưa ứng dụng về màn hình Home.
  2. Chụp ảnh màn hình: takeScreenshot: "screenshots/Home_Screen".
  3. Chạy compare.py so sánh với assets/Home_Screen.png.
- Kết quả mong đợi:
  + Tỷ lệ tương đồng (Match Percentage) >= 95%.
  + Layout và màu sắc gradient đồng nhất với bản thiết kế chuẩn.

[TC_HOME_UI_03] Kiểm tra hiển thị nội dung chi tiết của từng thẻ tính năng
- Mục tiêu: Xác nhận text tiêu đề và mô tả của từng thẻ hiển thị chính xác theo spec.
- Các bước thực hiện:
  1. Kiểm tra Card Template: Text "Template" và "Edit and Save Logo Template".
  2. Kiểm tra Card AI Studio: Text "AI Studio" và "Create unique logos and explore fresh styles with AI".
  3. Kiểm tra Card Create Logo: Text "Create Logo".
  4. Kiểm tra Card Auto Design: Text "Auto Design".
  5. Kiểm tra Card My Logo: Text "My Logo".
  6. Kiểm tra Card My Design: Text "My Design".
- Kết quả mong đợi: Toàn bộ text hiển thị đầy đủ, không bị cắt cụt (truncate) hoặc xuống dòng lỗi.
